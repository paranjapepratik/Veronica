briefVeronica v4 — what I read, what I think is wrong

I read veronica.py (39 KB, tkinter + Entrez + Ollama) and the README. Two problems are tangled together: the app looks dated, and the results are weak. The second one is not a UI problem — it's six specific things in the retrieval and scoring path. Designs below assume those get fixed, and the UI is built to show the fix (visible query, visible ranking reasons) rather than hide it.

BUG · MISSES PAPERS
Fetch Limit does nothing

_search_impl calls pubmed_search(..., max_results=show_n) — show_n, not fetch_n. So "Fetch 200" still retrieves 10. Every review you run is a top-10 PubMed relevance list. This alone explains most missing papers.

BUG · MISSES PAPERS
Silent full-text filter

Papers with no abstract or no PMC/DOI are dropped before you ever see them. Landmark older papers and many reviews vanish with no trace. Keep them, mark them no full text, let the researcher decide.

FIX · OFF-TOPIC HITS
Build the query, don't pass the box

Right now your raw keyword string goes straight to Entrez. Expand each concept into a MeSH + [tiab] OR-group, AND the groups together — and print the generated query in the UI so it's inspectable and editable. That's the single biggest precision win.

FIX · ARBITRARY SCORES
A rubric, not a vibe

One prompt asking for "1–10" on a 900-char abstract will never be stable. Score four named criteria 0–3 each — population, intervention/exposure, outcome, study design — each with a quoted span from the abstract as evidence. Sum = 0–12. Now the number is auditable and the "why" comes free.

FIX · TOO SLOW
Cheap pre-rank, then spend the LLM

Retrieve 200, rank locally (BM25 or embeddings on title+abstract — milliseconds, no model), then send only the top 40 to Ollama across a 4-thread pool with keep_alive set. Serial 15–40 s/paper becomes a couple of minutes for a real corpus.

FIX · PUBMED-ONLY
Three more keyless sources

Europe PMC (preprints + full text), OpenAlex (citation counts — the README says PubMed can't give them; OpenAlex can, free), Crossref (DOI metadata). All keyless, all offline-friendly to cache. Dedupe on DOI, keep a source badge per row.

Below: three directions for the interface. Reference them by id in chat — e.g. "go deeper on 1c's screening board, but with 1a's query bar".
